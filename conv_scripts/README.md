# EijiroConv

## `split.js`

`EIJIRO_UTF8.TXT` を読み込み、各行の見出しに応じて `split/` 以下のファイルに分割します。

- 英字で始まる見出しは、先頭の英字1～2文字を小文字にしてファイル名にします。例: `accent` → `ac.txt`、`a.` → `a.txt`
- 数字または記号で始まる見出しは `0before.txt` に出力します。
- それ以外の文字で始まる見出しは `zzzafter.txt` に出力します。
- `■` で始まらない行や見出しが空の行はスキップします。

実行方法:

```sh
node split.js
```

入力ファイルと出力ディレクトリは引数で変更できます。

```sh
node split.js 入力ファイル 出力ディレクトリ
```

実行時、出力ディレクトリ内の `a.txt`～`zzzafter.txt` など、スクリプトが扱う名前の既存 `.txt` ファイルは削除して作り直します。必要なデータがある場合は、実行前にバックアップしてください。

## `split_large.js`

`split/` 以下を調べ、サイズが1 MiB（1,048,576バイト）以上の英字2文字ファイルを先頭3文字のファイルに分割します。その後、同じサイズ条件を満たす英字3文字ファイルを先頭4文字に分割します。たとえば `ac.txt` は `acc.txt` などに分かれ、3文字でも大きいファイルは `acce.txt` などに分かれます。4文字ファイルはそれ以上分割しません。

分割した元ファイルは、各エントリーの振り分け後に削除されます。振り分け先がすでに存在する場合は、そのファイルに追記します。

実行方法:

```sh
node split_large.js
```

対象ディレクトリは引数で変更できます。

```sh
node split_large.js ディレクトリ
```

`split_large.js` を実行する前に `split.js` で分割ファイルを作成してください。
